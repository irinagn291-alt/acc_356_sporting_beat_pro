# Sporting Beat

Нативная офлайн-игра для iPhone и iPad, iOS 17 и новее. Внутреннее задание фабрики — `acc_356`.

Откройте [SportingBeat.xcodeproj](SportingBeat.xcodeproj), выберите схему **SportingBeat** и устройство. Готовая универсальная сборка для симулятора лежит в [SportingBeat.app](../../artifacts/genesis/studio.sportingbeat.acc356/motion-build/Release/Build/Products/Release-iphonesimulator/SportingBeat.app).

Монитор запускает немую сцену. На столе можно опробовать реквизит, затем включить красную лампу и записать собственный дубль. Цветные импульсы показывают моменты и дорожки. Полоса рядом с импульсом показывает, сколько осталось держать длинный звук. В монтажной линейке можно перемещать курсор, слушать дорожку соло и заменить звук между ручками диапазона. Просмотровая позволяет сравнить версии и открыть клип на весь экран. Сохранённый базовый дубль открывает следующий заказ, а выбранные кассеты по четырём видам спорта составляют финальный эфир.

## Сборка и проверка

Три исходника приложения находятся в `SportingBeat`. [Отчёт компилятора](../../artifacts/genesis/studio.sportingbeat.acc356/motion-build/compiled-sources.txt) перечисляет файлы для обеих архитектур, ресурсы и локали. Графика площадок, раскадровки, PCM-эффекты и локализации входят в пакет приложения.

`bash QA/check-rules.sh` проверяет оценку 16 сцен и рендер звука на macOS. Для симуляторов используйте изолированный запуск фабрики. Последние аргументы выбирают сценарий и уникальную папку результатов.

```sh
python3 /Users/belzephyrus/Documents/gambling_factory/gf/genesis/simulator_pool.py \
    TEMPLATE_UDID bash "$PWD/QA/check-motion.sh" iphone iphone-run
```

Режим `iphone` проверяет первый заказ и перезапуск. Режим `ipad` проходит все 16 заказов с чистого обычного сохранения и записывает повторы для приёмки движения. Сохранения, кадры, видео и XCTest-отчёты экспортируются до удаления временного устройства.

Снимки, видео и проверка движения собраны в [отчёте QA](../../artifacts/genesis/studio.sportingbeat.acc356/motion-review/REPORT.md).
